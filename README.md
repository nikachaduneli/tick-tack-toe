# Tic-Tac-Toe

This is a simple Tic-Tac-Toe game built with HTML, CSS, and JavaScript. It allows two players to play the classic Tic-Tac-Toe game in their browser. Players alternate turns to place "X" or "O" on the game board, and the game tracks the number of wins for each player.

## Features

- Two-player gameplay with alternating turns between "X" and "O".
- Displays the current player's turn and the winner's message.
- Option to restart the game and reset the board.
- Tracks the number of wins for both players.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

The project consists of the following files:

- `index.html`: The main HTML file that defines the structure of the Tic-Tac-Toe game.
- `style.css`: The stylesheet for styling the game layout and design.
- `script.js`: The JavaScript file that handles the game logic, including player turns, win conditions, and game restart functionality.

## How to Use

1. Clone the repository or download the files.
2. Open the `index.html` file in your browser.
3. The game will start automatically. Players will alternate between "X" and "O" by clicking on the empty cells.
4. When a player wins, the winning message will appear, and you can restart the game by clicking the restart button.
5. The number of wins for each player is displayed at the bottom of the page.
